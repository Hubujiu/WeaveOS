# 契约入口

先读根 AGENTS、当前任务 PRD 与 ADR-002；涉及登录必须再读 ADR-001。契约和业务验收先于实现，不能从 Handler/ORM 反向生成“需求”。

对外 HTTP 锁定 OpenAPI 3.2.1，内部真正跨服务接口用 proto3/gRPC；同进程不强制 RPC。标准版本与产品 v0.1.0、接口 /api/v1 独立。工具不兼容需验证/报告，不静默降级或假装兼容。

普通 JSON 按 ADR-002 的 code/message/data/meta，HTTP 状态码及无正文、下载/流式等例外必须按完整 ADR 处理；不把 REST Envelope 塞入 gRPC，不把 DB 行/框架对象直接作为 DTO。

接口定义、错误登记、兼容策略和协议测试同仓评审。生成代码不能手改，生成结果不能自证符合契约。修改 expected 必须有独立需求依据；破坏性变更不伪装为无影响。

本次仅创建入口。尚无端点规范、生成器、兼容验证或已批准错误码；禁止放一个空 paths 文件冒充完成 API 设计。
