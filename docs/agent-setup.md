# Agent 接入与启动自检

指令文件准确名称为 `AGENTS.md`，不是 `AGENT.md`。从根读取后，工作跨入子目录时仍须主动读沿途规则；不要假定启动时自动加载所有目录。

必须让执行任务的那个 Agent 环境拥有授权的 Notion 读取与相关数据库查询能力。仓库中的 URL 和 AGENTS 不会自行创建连接或授予权限；当前聊天的连接也不应被假定自动存在于另一工具/会话。默认只读，不为日常编码索要文档写权限。

启动自检：实际获取本项目页面 → 读取 PRD 和 Architecture 入口 → 定位当前迭代和适用 ADR 正文 → 报告来源状态、范围和验收条件 → 先写测试。只列出链接不算完成读取。

无法使用授权连接器/MCP时按根规则报告 BLOCKED；不要猜工具参数、借浏览器抓取私有页面或假称已读。离线快照需要明确授权及版本记录。

可用启动提示：

> 开始前执行仓库 AGENTS.md，主动读取本任务相关 Notion 正文。先报告来源和范围，再从需求设计测试并运行到预期失败；取得 RED 证据之后才写实现。不要根据实现生成测试预期。

Codex 官方指令加载说明： https://learn.chatgpt.com/docs/agent-configuration/agents-md 。本仓库没有写入你的个人 Codex 配置、OAuth 凭据或本机工具设置。
