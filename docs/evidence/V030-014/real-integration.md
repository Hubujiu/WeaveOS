# V030-014 real HTTP/PG browser verification

Verified 2026-10-03 against V030-013 detached HEAD `4dcad40f09d5d20c2d2d9f97a12c7e41b4630bed`. This is a local integration environment, not production. The Go bridge runs the actual `applications.Service` with `appstructure.Service`, PostgreSQL 18 and Redis session. Playwright's route adapter in `forms.real.spec.ts` forwards each browser API request to that service and injects the ephemeral test session because the Vite component harness is HTTP. The service handles authorization, CSRF, CAS, schema DDL and operation lookup. The adapter does not synthesize success responses. The lost-response test deliberately discards the returned HTTP response only after the service has committed.

To reproduce from an isolated V030-013 worktree with Go, goose, Docker, pnpm and Playwright installed:

1. Run PostgreSQL 18 on `127.0.0.1:55432` with database `weaveos_v014`, user `postgres`, password `weaveos_test`, and Redis on `127.0.0.1:56379`. These values are for a disposable local test only. Apply `db/migrations` with goose, then run `infra/runtime/roles.sql` as postgres.
2. Copy [real-browser-bridge_test.go](real-browser-bridge_test.go) into that worktree as `services/bff/internal/appstructure/v014_browser_bridge_test.go`. From `services/bff`, run `WEAVEOS_TEST_DATABASE_URL='postgres://postgres:weaveos_test@127.0.0.1:55432/weaveos_v014?sslmode=disable' WEAVEOS_TEST_REDIS_URL='redis://127.0.0.1:56379/0' go test ./internal/appstructure -run '^TestV014BrowserBridge$' -count=1 -v -timeout=16m`. The bridge writes an ephemeral `/tmp/v014-browser-bridge.json` with its local URL, app ID and test-only session tokens. It exits after 15 minutes or when `/tmp/v014-browser-bridge.stop` exists.
3. From V030-014 `apps/web`, run `pnpm exec playwright test --config src/applications/forms/playwright.forms.real.config.ts` with the three Playwright browsers installed. Run before the bridge exits. The test creates distinct directory and form names per browser and checks real reload, network-loss recovery, and a competing writer's CAS conflict.
4. Stop the bridge with `touch /tmp/v014-browser-bridge.stop` and remove the disposable containers. Do not copy the generated JSON to evidence or commit it.

Run logs: [real-browser-green.log](real-browser-green.log) (9/9), [v013-realpg-green.log](v013-realpg-green.log) (18/18). UI screenshots are in [screenshots](screenshots/). The remaining product-level verification is same-origin HTTPS after V030-012 mounts these exported components.
