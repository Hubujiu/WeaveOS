## 已实现

- 导出 `ApplicationStructurePanel`、`FormDesigner`、`FieldRenderer`、`FormPreview` 和 props，Shell 可显式挂载。目录树可键盘创建、改名、同应用移动，客户端防环；创建表单一次 POST，支持 `new_table`／`existing_table` 互斥来源。目录与视图输入带结构 CAS、稳定 operationId，未知结果可查询原操作或原请求重试。
- 原版三栏设计器有 11 类业务字段、只读系统字段、group／divider／description、12 栅格宽度、拖拽落点、顺序和键盘分组路径。字段配置含必填、默认值、精确十进制字符串、总精度／小数位数／有符号处理位数／舍入规则、时间精度／展示时区、稳定选项 ID。预览仅本地展示，不发送记录写请求，也没有发布动作。
- 唯一生效动作“保存”按服务器 `preflight → 影响/依赖 → 有效确认 token → 双版本 CAS PUT` 执行。旧选项有映射和重新预检，冲突、权限撤销、旧视图迟到响应、网络未知结果、脏退出均有明确保留/恢复路径。
- 原 Figma 设计器、预览、预检、确认、设置、脏状态、Home/Personnel 基线已读取；[来源与测试计划](../evidence/V030-014/readiness-and-test-plan.md)以及实际浏览器[状态截图](../evidence/V030-014/screenshots/)可复核。GSAP 固定 `3.15.0`，弹窗从触发按钮位置展开与反向收回，支持快速反向/重开、焦点恢复和减动效。原 Figma 节点没有 motion 数据，动画依据用户明确交互要求设计。
- `actorId` 来自 Shell 已验证 `user.id`，所有目录、表单、定义、候选与操作查询请求带 `X-Expected-Actor-Id`。按 actor/app/view 在当前 SPA 内隔离草稿与不可变原请求；401 与 `AUTH_SESSION_CHANGED` 分别通过 `onUnauthorized`、`onIdentityMismatch` 回传 Shell。未确认状态独立于 dirty；相同账号回到视图可继续查询原 operationId。对已成功预检的映射变更和过期确认令牌强制重新预检，回执必须匹配原作用域与请求。
- 成员及部门字段默认值使用 V030-013 冻结的 owner/Bootstrap 受控候选读接口，支持前缀搜索、游标分页与稳定 ID，保存由服务端重新检查来源；没有扩大普通记录编辑者权限。已有表字段可加入第二视图或在布局移除后重新放置，改类型需走服务器预检。
