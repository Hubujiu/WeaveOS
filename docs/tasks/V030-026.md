## Exact implementation contract
Read full ADR. Java class DeploymentGrpcService(DeploymentRegistry) extends generated DeploymentServiceImplBase. RPC validates strict UTF-8 bytes/size and identities before registry. Lookup validates complete identity/hash before reading and compares confirmed receipt. Outside a transaction only: active TransactionSynchronizationManager transaction rejects FAILED_PRECONDITION, avoiding provisional outer commit. Registry itself owns real commit; onNext only after returned committed result. INVALID_ARGUMENT invalid, ALREADY_EXISTS deploy conflict, FAILED_PRECONDITION lookup mismatch, UNAVAILABLE unexpected failure with fixed non-sensitive description. Do not expose SQL/XML/credentials.
Go NewClient(grpc.ClientConnInterface,time.Duration)(*Client,error); methods Deploy(ctx,*pb.DeployRequest)(*pb.DeploymentReceipt,error), Lookup(ctx,*pb.LookupRequest)(*pb.LookupResponse,error). Nil/bad config rejected (timeout positive <=30s). Validate request before Invoke, preserve exact bytes, deadline=min(parent,configured), no transparent retry. Validate every identity/hash in response, nonblank engine IDs and explicit Lookup oneof. Return nil+error on malformed confirmed/empty envelope. NotObserved remains typed and never means failure. Transport errors retain original gRPC status for caller classification.
Java server is test-owned Netty server, max inbound 1MiB+16KiB; no new production listener required. RootRpcFixtureMain is test source, exact synthetic b3-postgres fixture only, writes ephemeral port to /tmp/weaveos-rpc-ready and cleans schema on shutdown.
