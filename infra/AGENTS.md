# 基础设施

先读根 AGENTS、ADR-004/003 的当前状态；影响认证网络、Cookie 或故障处理时再读 ADR-001。拟议拓扑不是部署授权。

配置会改变行为：先确定预期与失败验证，再实现配置。不得用“只是 YAML/CI”逃避测试；不制造会无条件返回成功的验证步骤。

首版只引入真实需求，不能顺手部署 MQ、搜索、对象存储、Kubernetes、服务网格或额外网关。开发绑定优先 loopback，数据库、Redis 和内部管理端口不得默认公开。

Secret 外部注入、测试实例隔离、最小权限、备份恢复与回滚分别验证；配置存在不代表部署成功或恢复演练通过。不得把固定测试重置密码当成安全的生产配置。

本次没有 Compose/Docker 部署或业务流水线。仓库治理检查与未来产品 CI 分开；工作流写入权限不足必须报告，不能改用绕过权限的方法。
